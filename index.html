ABOUT THE GAME
⚡ PROJECT OVERVIEW

Designed as a high-octane vertical arcade shooter, this project blends classic shoot 'em up mechanics with dynamic power-up synergies and an in-depth hangar economy. Built to deliver fluid, fast-paced aerial combat directly in the browser, the game challenges players to dodge bullet waves, collect gold, and push their reflexes to the limit.
